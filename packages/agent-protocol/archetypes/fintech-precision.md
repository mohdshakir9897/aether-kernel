# Archetype: High-Precision Financial Instruments (`fintech-precision`)

## Target Environment
- **Operators**: Algorithmic traders, risk analysts, compliance auditors, accountants.
- **Physical Context**: High-density trading workstation (60cm viewing distance), fast visual scan required.

## Typographic Grammar
- **Font Stack**: `"IBM Plex Sans", -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`
- **Numerics**: Strict monospaced tabular figures, explicit sign notations (`+0.42%`, `-1.18%`).
- **APCA Requirement**: Minimum $|L_c| \ge 80$ for numeric balances and transaction amounts.

## Layout & Affordances
- **Density**: Ultra-dense tabular ledgers with sticky headers and column alignment (numbers right-aligned, text left-aligned).
- **Color Discipline**: Severe chromatic restraint. Muted neutrals with accent green/red reserved strictly for state direction (gain/loss), never for decoration.
- **Borders**: Hairline rules (`1px solid var(--border-hairline)`).
