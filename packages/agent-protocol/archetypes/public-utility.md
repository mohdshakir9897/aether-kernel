# Archetype: Public Utility & Civic Infrastructure (`public-utility`)

## Target Environment
- **Operators**: General public, citizens of all ages and cognitive abilities, assistive tech users.
- **Physical Context**: High-glare mobile screens, low-cost displays, variable eyesight.

## Typographic Grammar
- **Font Stack**: `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
- **APCA Requirement**: WCAG AAA standard ($|L_c| \ge 90$ for core body copy and actionable form controls).

## Layout & Affordances
- **Clarity**: High-contrast, large touch targets ($\ge 48\times 48\text{px}$), explicit focus rings.
- **Language**: Direct, plain language; zero marketing buzzwords or corporate jargon.
- **Prohibited**: Floating pill badges, low-contrast subtle text, decorative background filters.
