# RFC-004: Universal Agent Directives & Multi-Platform Adapters

- **Status**: Accepted / Implemented
- **Authors**: Aether Agent Protocol WG
- **Target**: `@aether-kernel/agent-protocol`

## Context
Linters can only operate after code has been generated. To solve aesthetic convergence at the source, AI coding agents must operate under systemic cognitive guardrails *prior* to token generation.

## Decision
Establish a mandatory 4-Gate operational protocol:
1. **Gate 1: Socratic Friction**: Agents must explicitly interrogate domain requirements, data density, operator sensory profiles, and physical display context before emitting markup.
2. **Gate 2: Mathematical Token Declaration**: Agents must formulate strict OKLCH palettes and Fibonacci spatial scales upfront with APCA bounds.
3. **Gate 3: Asymmetrical Layout Grammar**: Prohibition of symmetrical centered stacks in favor of dynamic optical balance.
4. **Gate 4: Adversarial Self-Healing Pre-flight**: Compulsory AST linting pass before finalizing response tokens.

Provide universal adapters across Cursor (`.cursorrules`), Windsurf (`.windsurfrules`), GitHub Copilot (`copilot-instructions.md`), Antigravity (`antigravity.json`), Aider (`aider.conf.yml`), Cline (`clinerules`), Claude Code (`claude-code.json`), Gemini, OpenAI Codex, Grok, v0, and Bolt.
